## 📖 About

**TGOW CrosshairV1** is a lightweight, customizable crosshair overlay designed for Windows 10/11. It provides a clean, always-on-top crosshair that works with any game or application without interfering with your gameplay. The overlay uses minimal system resources and offers multiple customization options including colors, sizes, and shapes.

> **Note:** The first preview video shows the interface in German for demonstration purposes. The actual downloaded software features a complete English interface.

---

## ✨ Features

- 🎯 **7 Unique Crosshair Shapes** - Plus, Dot, Circle, Circle+Dot, Cross with Gap, X-Shape, Triangle
- 🎨 **8 Vibrant Colors** - Neon Green, Red, Blue, Gold, Magenta, White, Orange, Cyan
- 📏 **6 Size Options** - From XS (5px) to XXL (30px)
- ⚡ **Ultra-Lightweight** - Only 17MB RAM usage, 0% CPU
- 🎮 **Game-Friendly** - Doesn't block any game inputs when menu is hidden
- 🖥️ **Click-Through** - Overlay doesn't interfere with mouse clicks
- 🔧 **Easy Controls** - Simple hotkey-based menu system
- 📱 **Auto-Recenter** - Automatically stays centered on screen
